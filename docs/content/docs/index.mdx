FdBook's Studio edits the pages of a [fumadocs](https://fumadocs.dev) site:
in Visual (the page as the site renders it) or Source (the MDX). It keeps
the page tree, the pages' files and the diagrams in step with the pages
that use them, lints each page against what the site gets wrong, and takes
every edit from a change request (a `cr/<slug>` branch with its own
worktree) through commit, preview and pull request. Coding agents (Claude
Code, Codex, omp, Hermes Agent) can work in a change request over ACP, with
the Studio's MCP tools, and their edits to existing pages come back as
suggestions to accept or reject.

These docs are a FdBook project themselves: the Studio's tests run on them.

## Run

From the repository root, after `npm install`:

```sh
npm run docs                     # the Studio on these docs, http://127.0.0.1:4310
npm run studio -- ../my-site     # the Studio on another fumadocs site
```

It needs Node 22.18 or newer, git with an `origin` that has `main`, and `gh`
for pull requests. Where the Studio finds the pages, their files and the
diagrams is in [Configuration](./guide/configuration.mdx); serving on
another address, sign-in and agents are in [Setup](./guide/setup.mdx).

## Where things are

<Diagram src="reference/studio-layout" caption="The Studio: one Node process serving the UI, the files and the agents." />

```text
packages/
  server/     @fdbook/server: one Node process for the API, the notes sync,
              the UI (through Vite), change requests, agents and MCP
  ui/         @fdbook/ui: the React UI (editor, sidebar, views, agent panel)
  shared/     @fdbook/shared: what both read (path policy, project areas,
              the shapes of the API)
  diagram/    @fdbook/diagram: diagram files, shared with a site
  mdx/        @fdbook/mdx: the MDX a site and the Studio share
  testing/    @fdbook/testing: test helpers, a Studio over a throwaway worktree
docs/         these docs, a FdBook project
```

Inside a package, a module imports another of the same package as
`#path/to/module.ts` (`imports` in its `package.json`) and its tests as
`#tests/…`; across packages, as `@fdbook/<package>/<module>.ts`.

## Checks

```sh

npm run types:check
npm run docs:lint
```

Run these before pushing. Details and known flakes are in
